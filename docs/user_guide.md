# Руководство пользователя

## Вход в систему

При открытии дашборда появляется форма входа.

**Учётные данные по умолчанию:**
- Логин: `admin`
- Пароль: `admin123`

После успешного входа токен сохраняется в браузере на 24 часа — повторный вход при обновлении страницы не требуется. Для выхода нажмите кнопку **Logout** в правом верхнем углу.

## Вкладка Overview

Главный экран с общей статистикой системы.

### Метрики (карточки вверху)

| Метрика | Описание |
|---|---|
| **Total Alerts** | Всего записей в базе данных |
| **Intrusions** | Количество обнаруженных вторжений |
| **Normal** | Количество нормальных соединений |
| **Detection Rate** | Доля вторжений от всех алертов |

### График топ-5 типов атак

BarChart показывает 5 наиболее часто встречающихся типов атак по данным из базы. Обновляется после каждой симуляции.

### Индикатор Telegram

- **Зелёная точка** — Telegram настроен, уведомления активны
- **Серая точка** — Telegram не настроен

## Вкладка Live Detection

Симуляция обнаружения вторжений на реальных данных CICIDS2017.

### Как использовать

1. Нажмите кнопку **Run Simulation**
2. Система выберет 100 случайных строк из датасета
3. Ансамбль ML прогонит каждую строку через 4 модели
4. Результаты отобразятся в таблице в реальном времени

### Таблица результатов

| Колонка | Описание |
|---|---|
| **#** | Номер строки |
| **True Label** | Реальная метка из датасета (для проверки) |
| **Prediction** | Решение ансамбля: INTRUSION / NORMAL |
| **IF / LOF / SVM / RF** | Голос каждой модели (1 = аномалия, 0 = норма) |
| **Confidence** | Доля моделей, проголосовавших за атаку |
| **Attack Type** | Тип атаки (для INTRUSION) |

### Интерпретация результатов

- **Красный INTRUSION** — ансамбль определил вторжение (≥2 голосов)
- **Зелёный NORMAL** — трафик в норме
- **Confidence 100%** — все 4 модели согласны
- **Confidence 50%** — 2 из 4 моделей проголосовали за атаку (минимальный порог)

### Итоговая статистика

После симуляции отображается:
- Количество обнаруженных вторжений из 100
- Detection rate
- Голоса каждой модели (сколько раз проголосовала за аномалию)

## Вкладка Packet Capture

Live-захват реального сетевого трафика на вашем компьютере.

> **Требования:** Npcap (Windows) или запуск от root (Linux/Mac). Бэкенд должен быть запущен с правами администратора.

### Как использовать

1. Выберите сетевой интерфейс в выпадающем списке (например, Wi-Fi или Ethernet)
2. Нажмите **Start Capture**
3. Система начнёт перехватывать сетевые пакеты
4. Результаты появляются в таблице по мере завершения потоков
5. Нажмите **Stop Capture** для остановки

### Что происходит внутри

- Пакеты группируются в **5-tuple потоки** (src_ip, dst_ip, src_port, dst_port, protocol)
- Поток завершается при TCP FIN/RST или по таймауту 30 секунд
- Из каждого потока вычисляются 78 CICIDS2017-совместимых признаков
- Ансамбль ML анализирует поток и выносит вердикт
- Результат мгновенно появляется в таблице через WebSocket

### Таблица потоков

| Колонка | Описание |
|---|---|
| **Src IP : Port** | Источник соединения |
| **Dst IP : Port** | Назначение соединения |
| **Protocol** | TCP или UDP |
| **Bytes** | Объём переданных данных |
| **Prediction** | INTRUSION / NORMAL |
| **IF / LOF / SVM / RF** | Голоса моделей |

### Статус захвата

Вверху отображаются счётчики: пакетов перехвачено, потоков завершено, вторжений обнаружено.

## Вкладка Alerts

База данных всех обнаруженных событий.

### Фильтрация

Кнопки над таблицей:
- **All** — все записи
- **Intrusions** — только вторжения
- **Normal** — только нормальный трафик
- **Refresh** — обновить данные

### Таблица алертов

| Колонка | Описание |
|---|---|
| **Timestamp** | Время события |
| **Source IP** | IP-адрес источника |
| **Destination IP** | IP-адрес назначения |
| **Proto** | Протокол |
| **Prediction** | Красный INTRUSION / зелёный NORMAL |
| **Attack Type** | Цветной бейдж типа атаки |
| **Confidence** | Уверенность ансамбля (%) |
| **Models Voted** | Бейджи IF / LOF / SVM / RF (красный = проголосовал за атаку) |

### Цветовая кодировка типов атак

| Цвет | Тип атаки |
|---|---|
| Красный | DDoS, DoS |
| Жёлтый | PortScan |
| Оранжевый | Brute Force |
| Фиолетовый | Bot |
| Бирюзовый | Infiltration |
| Тёмно-красный | Heartbleed |

### Экспорт данных

- **Export CSV** — скачать все алерты в формате таблицы (Excel, Google Sheets)
- **Export PDF** — скачать все алерты в виде PDF-отчёта (A4 landscape)

### Пагинация

Таблица показывает по 20 записей. Используйте кнопки **Prev** / **Next** для навигации.

## Вкладка Models

Информация об обученных моделях.

### Карточки моделей

Каждая из 4 моделей представлена карточкой с:
- Названием и типом (SUPERVISED / UNSUPERVISED)
- Размером обучающей выборки
- Ключевыми гиперпараметрами
- Описанием принципа работы

### Типы моделей

- **UNSUPERVISED** (синий бейдж) — Isolation Forest, LOF, One-Class SVM  
  Обучены только на нормальном трафике, обнаруживают отклонения.

- **SUPERVISED** (зелёный бейдж) — Random Forest  
  Обучен на размеченных данных, знает паттерны атак напрямую.

## Telegram уведомления

При обнаружении вторжения с **confidence ≥ 75%** в Telegram приходит сообщение:

```
🚨 INTRUSION DETECTED
Type: DDoS
Confidence: 100%
Source IP: 192.168.1.45
Protocol: TCP
Models: IF✓ LOF✓ SVM✓ RF✓
Time: 2026-05-14 12:34:56
```

Уведомления приходят как из симуляции (/simulate), так и из live capture.

## Типичный сценарий использования

1. Открыть дашборд, войти как `admin`
2. Перейти на **Live Detection** → нажать **Run Simulation**
3. Изучить результаты: какие модели сработали, какие типы атак обнаружены
4. Перейти на **Alerts** → посмотреть сохранённые алерты
5. Нажать **Export CSV** для сохранения отчёта
6. Перейти на **Overview** → увидеть статистику и топ атак
7. (Опционально) Перейти на **Packet Capture** → выбрать интерфейс → **Start Capture**
