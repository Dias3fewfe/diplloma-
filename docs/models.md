## Предобработка данных

**Файл:** `backend/pipeline/preprocess.py`

1. Загрузка сырого CSV (CICIDS2017.csv)
2. Удаление строк с пропущенными значениями
3. Удаление дубликатов
4. Удаление столбцов с >40% пропусков
5. Замена inf/-inf на NaN и удаление
6. Обучение `StandardScaler` на числовых признаках
7. Применение скейлера, сохранение `cleaned.csv` и `scaler.pkl`

StandardScaler нормализует каждый признак: `z = (x - μ) / σ`. Это критично для LOF и SVM, чувствительных к масштабу.

## Ансамбль из 4 моделей

### Принцип ансамбля

Ансамблирование объединяет несколько слабых классификаторов в один сильный. В данной системе используется **голосование большинством**:

```
INTRUSION если: vote_IF + vote_LOF + vote_SVM + vote_RF ≥ 2
```

Комбинирование трёх unsupervised-детекторов с одним supervised-классификатором снижает как False Positive (false alarm), так и False Negative (пропуск атаки).

---

### 1. Isolation Forest

**Тип:** Unsupervised (обнаружение аномалий)  
**Обучающая выборка:** 200 000 BENIGN-строк  

**Принцип работы:**

Isolation Forest строит ансамбль случайных деревьев изоляции. Каждое дерево рекурсивно разбивает пространство признаков случайными порогами. Аномальные точки (отличающиеся от нормы) изолируются за меньшее количество разбиений — их путь в дереве короче.

```
Anomaly Score = 2^(-E(h(x)) / c(n))

где E(h(x)) — средняя глубина изоляции,
    c(n)    — нормализующая константа.
```

**Гиперпараметры:**

| Параметр | Значение | Описание |
|---|---|---|
| `n_estimators` | 100 | Количество деревьев |
| `max_samples` | auto | Подвыборка для каждого дерева |
| `contamination` | 0.05 | Ожидаемая доля аномалий (5%) |
| `random_state` | 42 | Seed для воспроизводимости |
| `n_jobs` | -1 | Использовать все ядра CPU |

**Преимущества:** линейная сложность O(n), работает на высокоразмерных данных, устойчив к шуму.

---

### 2. Local Outlier Factor (LOF)

**Тип:** Unsupervised (обнаружение аномалий)  
**Обучающая выборка:** 50 000 BENIGN-строк  

**Принцип работы:**

LOF сравнивает локальную плотность каждой точки с плотностью её k ближайших соседей. Точки в разреженных областях (далеко от соседей) получают высокий LOF-score и считаются аномалиями.

```
LOF_k(p) = (Σ lrd_k(o) / k) / lrd_k(p)

где lrd_k(p) — локальная плотность достижимости точки p,
    o        — k-ближайшие соседи p.
```

Значение LOF > 1 указывает на аномалию. В системе используется `novelty=True` для предсказания на новых данных.

**Гиперпараметры:**

| Параметр | Значение | Описание |
|---|---|---|
| `n_neighbors` | 20 | Число ближайших соседей k |
| `contamination` | 0.05 | Порог классификации |
| `novelty` | True | Режим предсказания на новых данных |
| `n_jobs` | -1 | Параллельность |

**Преимущества:** хорошо обнаруживает локальные аномалии, не требует предположений о форме распределения.

---

### 3. One-Class SVM (OC-SVM)

**Тип:** Unsupervised (обнаружение новизны)  
**Обучающая выборка:** 30 000 BENIGN-строк  

**Принцип работы:**

One-Class SVM строит гиперплоскость в пространстве признаков, которая отделяет нормальные данные от начала координат с максимальным зазором. Точки, попадающие на «неправильную» сторону гиперплоскости, классифицируются как аномалии.

С RBF-ядром (Radial Basis Function) SVM работает в высокоразмерном пространстве признаков через ядровой трюк:

```
K(x, x') = exp(-γ ||x - x'||²)
```

**Гиперпараметры:**

| Параметр | Значение | Описание |
|---|---|---|
| `kernel` | rbf | Радиальная базисная функция |
| `nu` | 0.05 | Верхняя граница доли аномалий |
| `gamma` | scale | γ = 1 / (n_features × var(X)) |

**Преимущества:** эффективен при малых обучающих выборках, хорошо работает с RBF-ядром на нормализованных данных.

**Ограничение:** квадратичная сложность O(n²) — поэтому выборка ограничена 30 000 строк.

### 4. Random Forest (Supervised)

**Тип:** Supervised (бинарная классификация)  
**Обучающая выборка:** 150 000 строк (все классы, стратифицированно)  

**Принцип работы:**

Random Forest — ансамбль решающих деревьев, обученных на случайных подвыборках данных и признаков (bagging + feature randomness). Предсказание — голосование деревьев.

В отличие от трёх unsupervised-моделей, Random Forest **знает о существовании атак** — он обучен на размеченных данных и может напрямую классифицировать трафик как BENIGN (0) или ATTACK (1).

**Стратифицированная выборка** обеспечивает представление всех классов пропорционально их доле в датасете, включая редкие атаки (Heartbleed, Infiltration).

**Параметр `class_weight='balanced'`** автоматически взвешивает классы обратно пропорционально их частоте — важно при дисбалансе (70% BENIGN vs 30% атаки).

**Гиперпараметры:**

| Параметр | Значение | Описание |
|---|---|---|
| `n_estimators` | 100 | Количество деревьев |
| `class_weight` | balanced | Веса классов по частоте |
| `max_features` | sqrt | Признаков на каждом разбиении |
| `random_state` | 42 | Seed |
| `n_jobs` | -1 | Параллельность |

**Результат в тестировании:** 100% Recall, 0% FPR на тестовой выборке — RF является доминирующей моделью в ансамбле.

## Классификатор типов атак

**Файл:** `backend/pipeline/train_classifier.py`  
**Тип:** Мультиклассовая классификация (9 классов атак)

Отдельный Random Forest с 200 деревьями обучен на 150 000 строках со всеми метками (не только бинарными). Запускается **после** ансамбля — только для строк, классифицированных как INTRUSION — и определяет конкретный тип атаки.

**Входные данные:** те же 77 числовых признаков  
**Выходные данные:** строка (например, `"DDoS"`) + вероятность (`confidence`)

## Сравнение подходов

| Подход | Плюсы | Минусы |
|---|---|---|
| Только unsupervised | Не требует меток, обнаруживает новые типы атак | Высокий FPR, низкий Recall |
| Только supervised | Высокий Recall и Precision на известных атаках | Не обнаруживает неизвестные атаки |
| **Ансамбль (данный подход)** | Баланс между двумя подходами, устойчивость к ошибкам | Сложнее в интерпретации |

Ансамбль снижает риск пропуска атаки (за счёт RF с 100% Recall) и одновременно фильтрует ложные срабатывания unsupervised-моделей.
